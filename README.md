# IDPortrait
A lightweight and efficient AI ID photos tools


1. 【风控预检模块】
   - RetinaFace ONNX：人脸检测 + 5关键点，校验单人、无遮挡、不闭眼
   - 人脸质量评估模型：打分清晰度、光照、反光
3. MODNet ONNX：人像抠图，输出alpha蒙版
4. FaceParsing ONNX：人脸语义分割，输出皮肤掩码（美颜用）
5. 【美颜管线 Go原生图像算法】
   - 双边滤波：仅皮肤区域，保护五官
   - 肤色均衡、提亮面部，可调节强度0~1（证件照建议0.2~0.4，禁止过度美颜）
   - 眼睛轻微锐化，提升通透感
6. 构图裁切：基于5关键点，自动居中、肩线对齐，按照国标控制头身比例
7. 背景合成：填充纯色背景，蒙版羽化融合，消除抠图白边

生成证件照后，和原图做人脸特征比对，校验美颜没有大幅度改变人脸
